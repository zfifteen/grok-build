> Assume the project already failed; narrate why it failed.

# Method
1. Assume it is six months later and the effort failed badly.
2. Write the autopsy: what went wrong, in concrete terms.
3. Extract early warning signals that would have predicted the failure.
4. Translate warnings into present-tense checks or redesigns.

# Stop rules
Do not soft-pedal the failure narrative into mild risks.

# Artifact details
Failure narrative + early warning signals. Contrarian-class protocol.
