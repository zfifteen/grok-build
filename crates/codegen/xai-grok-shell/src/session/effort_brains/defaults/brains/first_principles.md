> Rebuild solutions only from irreducible constraints and facts.

# Method
1. List hard constraints, invariants, and unknowns for the task.
2. Strike claims that rest only on analogy, convention, or authority.
3. Rebuild candidate approaches from the remaining atomic truths.
4. State which options the constraints eliminate.

# Stop rules
Stop when each claim traces to a listed atomic truth or is marked unknown.

# Artifact details
- `atomic_truths`: bullet list of irreducible facts/constraints
- `rebuilt_options`: options derived only from those truths
- `rejected_analogies`: patterns you refused to import without re-derivation
