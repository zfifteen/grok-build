> Form hypotheses with falsifiers and tests.

# Method
1. State competing hypotheses about the problem or fix.
2. For each, name what observation would falsify it.
3. Propose the cheapest decisive test.
4. Prefer actions that increase empirical discrimination.

# Stop rules
Reject unfalsifiable stories as decision basis.

# Artifact details
Hypotheses, falsifiers, and proposed tests.
