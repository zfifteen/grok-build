> Build the strongest fair counter-case and remaining tensions.

# Method
1. State the leading approach as charitably as possible.
2. Build the strongest opposing case a smart critic would make.
3. Note where both sides still have force (tensions, not forced fake consensus).
4. Hand the lead synthesis genuine disagreements to resolve.

# Stop rules
No strawmen. No papering over real conflicts.

# Artifact details
Steelman of the lead path + strongest counter + residual tensions.
