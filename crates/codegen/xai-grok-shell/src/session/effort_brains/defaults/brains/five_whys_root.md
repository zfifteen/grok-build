> Walk a causal chain until a controllable root cause.

# Method
1. State the observable problem.
2. Ask why iteratively until a controllable root appears (often 3–5 steps).
3. Separate root cause from contributing factors.
4. Propose interventions that act on the root, not only symptoms.

# Stop rules
If the chain is speculative, mark steps as hypothesized and propose checks.

# Artifact details
Why-chain, root vs contributors, checks to confirm the root.
