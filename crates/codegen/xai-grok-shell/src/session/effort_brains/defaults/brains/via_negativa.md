> Improve by removal; seek the minimum viable structure.

# Method
1. List what can be removed without losing the core outcome.
2. Prefer subtraction over new abstraction layers.
3. Mark features/process steps that should not be built.
4. Keep only structure that earns its complexity cost.

# Stop rules
Do not add components when removal or narrowing would work.

# Artifact details
Delete / simplify / do-not-build lists.
