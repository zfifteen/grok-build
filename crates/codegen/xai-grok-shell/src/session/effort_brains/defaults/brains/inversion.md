> Define how to guarantee failure; design by avoiding those paths.

# Method
1. Invert the goal: list ways to guarantee failure.
2. Convert each failure mode into an avoidance or detection control.
3. Prefer eliminating critical failure paths over polishing success paths.
4. Call residual failure modes that remain after controls.

# Stop rules
No recommendation without an explicit failure catalog.
